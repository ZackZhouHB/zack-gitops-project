    <p>Here's a summary of the actions I took to delete an AWS account using <code>aws-nuke</code> as it is at the end of free tier I donot need it anymore to aviod cost:</p>

    <p><strong>1. Install aws-nuke:</strong></p>
    <pre style="background-color: #f5f5f5; padding: 15px; white-space: pre-wrap; word-wrap: break-word; max-width: 100%; overflow-x: auto;">apt install aws-nuke</pre>
    <p>This command installs <code>aws-nuke</code>, a tool used to delete AWS resources in an account. It requires AWS credentials and the correct configuration file to specify what resources to remove.</p>

    <p><strong>2. Create a nuke-config.yaml, which will be used during execution:</strong></p>
    <pre style="background-color: #f5f5f5; padding: 15px; white-space: pre-wrap; word-wrap: break-word; max-width: 100%; overflow-x: auto;">
root@zackz:/mnt/f/aws-nuke# vim nuke-config.yaml

regions:
  - ap-southeast-2
  - global

account-blocklist:
  - "85xxxxxxxx42"  # production account ID

accounts:
  "85xxxxxxxx15":   # Joe Account to be deleted
    filters:  
      IAMUser:
        - "nuke"     # the user excluded from deletion action
      IAMUserPolicyAttachment:   
        - "nuke -> AdministratorAccess"
      IAMUserAccessKey:
        - "nuke -> AKIA4MTWMCWF7T6HLYXE"
    </pre>
    <p>
      <strong>regions:</strong> Specifies which AWS regions the <code>aws-nuke</code> tool should scan.<br>
      <strong>account-blocklist:</strong> Ensures that certain accounts (like the production account) are not accidentally nuked.<br>
      <strong>accounts:</strong> Lists the accounts to be nuked and specifies any filters for exclusions (like the user "nuke" in this case). Filters prevent specific resources, like users or keys, from being deleted.
      I execluded a user nuke so it can perform the remove action.  
    </p>

    <p><strong>3. Ensure AWS Credentials:</strong></p>
    <p>Before running the command, make sure the AWS CLI is configured with credentials (using <code>aws configure</code> or a profile). I tested the credentials with:</p>
    <pre style="background-color: #f5f5f5; padding: 15px; white-space: pre-wrap; word-wrap: break-word; max-width: 100%; overflow-x: auto;">

aws iam list-account-aliases --profile joe
</pre>
    <p>This command checks if the alias for the <code>joe</code> account exists. If no alias exists, you must create one.</p>

    <p><strong>4. Create an Account Alias:</strong></p>
    <pre style="background-color: #f5f5f5; padding: 15px; white-space: pre-wrap; word-wrap: break-word; max-width: 100%; overflow-x: auto;">aws iam create-account-alias --account-alias aws-joe-85xxxxxxxx15 --profile joe</pre>
    <p>AWS requires an account alias for the <code>aws-nuke</code> process. Since my account did not have an alias, I just created one. The alias is important for <code>aws-nuke</code> because it checks the alias before proceeding with deletion to prevent accidentally deleting important accounts. If an alias is already taken, you need to choose a different one.</p>

    <p><strong>5. Run aws-nuke with Dry-Run:</strong></p>

    <p><strong>6. Confirm the Resources to be Nuked:</strong></p>
    <p>During the dry run, <code>aws-nuke</code> listed resources like EC2 instances, IAM roles, policies, and security groups that would be removed. You can review the list to ensure that only the intended resources are being marked for deletion.</p>

    <p><strong>Key Takeaways:</strong></p>
    <ul>
        <li><strong>Why Create an Account Alias:</strong> AWS requires an account alias for safety purposes. This prevents accidental deletions by ensuring that only the intended account is nuked.</li>
        <li><strong>Why Use Filters:</strong> Filters prevent critical resources (like specific IAM users or access keys) from being deleted.</li>
        <li><strong>Dry Run Is Crucial:</strong> Always perform a dry run to verify what resources are marked for deletion.</li>
        <li><strong>Account Alias Verification:</strong> If you see <code>NoSuchEntity</code> or similar errors, double-check the alias set for the account and ensure it's valid.</li>
    </ul>
