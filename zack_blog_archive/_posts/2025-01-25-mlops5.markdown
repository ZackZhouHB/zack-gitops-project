## Business Problem
Pneumonia causes over 2.5 million deaths annually worldwide. Traditional diagnosis through chest X-ray analysis is time-consuming and requires expert radiologists. This project aims to develop an automated deep learning system to classify pneumonia from chest X-rays with high accuracy, potentially assisting healthcare professionals in faster diagnosis.

## Purpose
Here I will use local environment with Pytorch and Jupiter Notebook to: 
- Demonstrate end-to-end development of medical image classifier
- Using Kaggle dataset for NIH Chest X-Ray image processing
- Create baseline model for pneumonia detection (Normal vs Pneumonia)
- Local GPU acceleration for model training and prediction

## Typical ML steps to achieve image classifier: 
1. **Data Acquisition**: 
   - Source NIH Chest X-Ray dataset from Kaggle
   - 5,863 validated images (Train/Test/Val split)

2. **Preprocessing**:
   - Standardize image size (224x224px)
   - Normalize pixel values
   - Organize into class-specific directories

3. **Exploratory Analysis**:
   - Class distribution visualization
   - Sample image inspection

4. **Model Development**:
   - Leverage pre-trained ResNet18
   - Custom head for binary classification
   - GPU-accelerated training

5. **Evaluation**:
   - Accuracy metrics
   - Model persistence

import torch
import torch.nn as nn

from torch.utils.data import DataLoader, Dataset
from torchvision import transforms, models
from PIL import Image
import pandas as pd
import os

# Define the dataset class for loading chest X-ray images
class ChestXRayDataset(Dataset):
    def __init__(self, dataframe, directory, transform=None):
        self.dataframe = dataframe
        self.directory = directory
        self.transform = transform

    def __len__(self):
        return len(self.dataframe)

    def __getitem__(self, idx):
        img_path = os.path.join(self.directory, self.dataframe.iloc[idx, 1])
        image = Image.open(img_path).convert('RGB')
        label = self.dataframe.iloc[idx, 0]
        if self.transform:
            image = self.transform(image)
        return image, label

# Load .lst files

import torch
from torchvision import transforms
from PIL import Image

model = models.resnet18(pretrained=False)
model.fc = nn.Linear(model.fc.in_features, 1)

# Load the trained model weights
model.load_state_dict(torch.load("local_image_classifier_model.pth"))
model.eval()  # Set the model to evaluation mode

# Define the same transformations used during training
transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
])

# Function to preprocess and predict
def predict_image(image_path, model, transform):
    # Load and preprocess the image
    image = Image.open(image_path).convert('RGB')
    image = transform(image).unsqueeze(0)  # Add batch dimension

    # Make a prediction
    with torch.no_grad():
        output = model(image)
        prediction = torch.sigmoid(output).item()  # Convert logits to probability

    # Interpret the prediction
    if prediction > 0.5:
        return "Pneumonia (Positive)"
    else:
        return "Normal (Negative)"

# Path to the image you want to test
image_path = "data/chest_xray/val/val_normal3.jpeg"

# Get the prediction
result = predict_image(image_path, model, transform)
print(f"Prediction: {result}")
